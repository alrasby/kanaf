# Kanaf AI — independent evaluation workflow (not yet released)

This utility checks mathematical *holdout* evidence. It does **not** train a
model, verify the real provenance/licensing of input files, or assert that
Kanaf has a usable production AI. Synthetic fixtures are only unit tests.

1. Independently procure a legally licensed and human-validated Android APK
   malware/benign dataset. Do not upload APKs or private files to this repo.
2. Extract all **seven** Kanaf feature-schema-v1 structural attributes for
   each sample using the exact Android extraction implementation; reject missing
   fields, and document device/ABI and extraction errors separately.
3. Train outside the application and preserve reproducible model/source splits.
   Use **independent collection sources** for holdout data, in addition to
   de-duplicating by SHA-256 to avoid leakage.
4. Produce a local UTF-8 JSONL (one record per sample):
   \`{"sha256":"<64-lowercase-hex>","split":"train","label":0,"source":"training_provider"}\`
   \`{"sha256":"<64-lowercase-hex>","split":"holdout","label":1,"source":"independent_provider","score":0.92}\`
   Scores must be generated by the exact *frozen* model that would ship.
   Every source must have verifiable licensing and labeling documentation.
5. Evaluate privately: \`python3 tools/evaluate_model.py --input /private/holdout.jsonl --output /private/metrics.json\`.
   The tool fails if source overlap, duplicate hashes, missing labels, invalid
   scores, fewer than **5,000 holdout examples** (**2,000** malicious and
   **2,000** benign minimum), **AUC < 0.90**, **FPR > 0.005**, or
   **recall < 0.85**. These are the current minimum gates encoded by
   \`VerifiedLinearThreatModel\`, not a claim of real achieved performance.
6. Independently audit source rights, feature leakage, model threshold,
   per-family detection rates, calibration, device latency/CPU/battery, false
   positives, and drift. Sign the exact final weights with the publisher's
   offline key and pin only the verification public key in the release APK.

**Current state:** no real signed weights, independent corpus, metrics
or hardware benchmark exists. \`UnavailableThreatModel\` is the correct
production-facing result until those conditions are satisfied.
